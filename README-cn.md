# AuraAgent

**[English](README.md)** · **[想看技术架构文档？→](docs/ARCHITECTURE-cn.md)**

*一个跑在你自己电脑上的私人 AI 团队——而且从不隐瞒它在做什么。*

---

## AuraAgent 是什么？

想象一下，你自己的电脑上住着一个小而能干的助理团队：能帮你上网调研、管理笔记和日程、整理文件、记住你之前跟它说过的事，甚至在你允许的情况下学习全新的技能。而且跟大多数 AI 工具不一样，它从不在一个黑箱里悄悄工作——它走的每一步都会实时讲给你听。

这就是 AuraAgent。它不是一个只会在对话框里回答问题的聊天机器人，而是一个真的能替你**做事**的系统——读一份文件、查一个话题的最新新闻、安排一个日程、写一份文档、连上你真实的 Google 日历——并且在做任何要紧的事之前，永远先把要做的事情讲清楚。

它完全运行在你自己的电脑上，用你自己的 API Key。它是怎么想的、做了什么，没有任何一部分藏在你看不见的代码黑箱里。

这份文档是写给所有对 AuraAgent 感兴趣的人看的——不需要任何编程背景。如果你是开发者，想看类名、文件路径、设计取舍这些细节，[技术架构文档](docs/ARCHITECTURE-cn.md)是它们的家。

## 第一章——它背后的理念

三个理念贯穿了 AuraAgent 的一切设计，值得先弄明白，因为它们解释了"为什么它会这样表现"。

**1. 没有任何事是藏起来的。**
AuraAgent 走的每一步——它在想什么、准备用哪个工具、工具返回了什么——都会实时打在你面前，并且存进一份你随时能回看的记录里。不存在"相信我，它正在处理"这种推理过程消失不见的时刻。你能像看一个同事说出他的思考过程一样，看着它思考。

**2. 有风险的事，它一定先问你。**
AuraAgent 会按"万一出错会有多糟"给自己的行动分级。读一份文件、上网查点东西？低风险、可逆，它直接做。删除一个文件、截取你整个屏幕、安装一项全新能力、连接一个外部服务？它会停下来，把要做的事和理由完整摆给你看，等你明确说"是"或"否"。每一次都是这样，没有例外，不会有"就这一次不问了"。

**3. 它能成长——但只能在你允许的前提下。**
如果 AuraAgent 遇到一件它不会做的事，它不会简单地失败了事。它可以给自己写一个小工具、给团队招募一个新的专员，或者连接一个已经会做这件事的外部服务——但在这么做之前，一定会先把它打算做的事情完整地讲给你听，让你的"同意"是一个真正知情的决定，而不是走个过场。

## 第二章——它到底能做什么？

按"你实际会用它来做什么"来梳理一遍它的能力：

- **上网调研。** 它能抓取、读取网页，提交表单，下载文件。它还内置了几项市场/行业研究的专长——给它一个话题，比如"电动车"或"AI芯片"，它就能拉取近期真实的新产品、技术趋势或大公司动向的新闻标题。
- **记笔记。** 它能创建、读取、修改、全文搜索一整个 Markdown 笔记库——你可以让它指向一个你已经在用的目录（比如一个 Obsidian 笔记库），而不是一个 AuraAgent 自己管的文件夹。
- **管理日程和待办事项。** 默认是一个本地、私密的日历/任务清单。如果你愿意，也可以让它连上你**真实的** Google 日历（一次性设置，见第五章），之后它就能真的读取、创建、修改、删除你日历上的日程。
- **管理你电脑上的文件**——限定在你指定的一个文件夹内，绝不是你的整个硬盘。它能在那里列目录、读写文件、移动、复制、搜索，也能做精确的局部替换（只替换文件里某一段确定的文字，不用为了一个小改动把整个文件重写一遍）——维护一份要不断增量更新的长笔记或文档时特别有用。它还能调用 Anthropic 官方的文件管理工具做更高级的操作。
- **读写真正的文档。** Word、PowerPoint、Excel 文件都能读取、从零生成、也能编辑（追加内容，或做简单的查找替换）；PDF 能读取（限文字版——扫描版没有 OCR，读不出来）。不需要额外配置。
- **操作你的电脑桌面**，以小范围、受监督的方式：读写剪贴板、截一张屏、看看有哪些程序在运行并关掉卡住的、弹一条桌面通知。
- **记住关于你的事。** 它既能维护一份简明的、结构化的"你的偏好和习惯"档案（每次都会自动展示给它看），也能维护一个可搜索的、你要求它记住的具体事实库。
- **对长期工作持续积累。** 你可以创建一个具名的"Project"（一个研究课题、一项长期工作——任何事都行），AuraAgent 会一直维护一份精简、最新的"进展如何"摘要，这样下周再捡起来时不用从零开始。详见第七章。
- **按你要求的时间点执行任务。** 用自然语言跟它说一次，它之后会自己再跑一遍——可以是某个具体时间点执行一次，也可以是周期性的（每小时/每天/每周指定几天/每月/每年），到点不需要你在场。详见第八章。
- **在你批准的前提下学习新技能。** 如果现有能力都做不到你要的事，AuraAgent 可以给自己写一个小的、单一用途的工具，搜索一个现成工具的公开索引，或者连接一个知名的外部服务——但永远是先把打算做的事完整摆给你看、拿到你的许可之后才会动手。

开箱即用，AuraAgent 自带一个小小的起步团队：一个**总管**（orchestrator）直接处理你的请求，并能委派给两位专员——一个**调研员**（researcher，负责网络调研、计算、市场研究）和一个**日程管理员**（scheduler，负责日历和待办）。以后可以继续扩充团队，可以让 AuraAgent 自己提议新成员，也可以你自己直接配置。

## 第三章——打个比方：它是怎么"思考"的

把 AuraAgent 想象成一家很小的公司，你是老板。

有一位**总管**——也就是"orchestrator"——负责接待你的每一个请求。简单的事，他自己当场就办了。需要专业技能的事，他会转交给团队里对的人：擅长挖信息的**调研员**，或者把日历和待办打理得井井有条的**日程管理员**——办完再把结果带回来给你。

关键的地方在于：这间办公室**是玻璃做的**。你能看到总管把想法说出来的过程，能看到他什么时候、为什么把一件事转交给某位专员，也能看到那位专员自己的工作过程实时嵌套显示在总管的记录里。如果两位专员同时在处理你请求的不同部分，你看到的是他们并行工作的样子，不是一团乱糟糟的交错文字。

而且跟一家普通公司不一样，这家公司能自己壮大——招募新专员、添置新工具，甚至接入外部供应商——但每一次这样的变化都必须先完整地摆在你面前，经你批准。没有谁能不经你同意就加入团队，也没有哪个外部服务能不经你同意就被连上。

## 第四章——这种安全感从哪里来

AuraAgent 不会一视同仁地对待自己的每一个动作。它会把要做的事分成几档风险等级，等级不同，行为也不同：

- **常规、可逆的事**（读一份文件、查点东西、看看日历）：直接做。
- **可能丢失或覆盖东西的事**（删除一个文件、修改一个标记为重要的日程）：先停下来直接问你一句是或否，并说清楚具体会影响到什么。
- **可能暴露隐私的事**（截取你的整个屏幕）：永远先问，并且明确讲清楚——这会截取**你屏幕上当前的一切**，不只是跟这次对话相关的内容。
- **改变 AuraAgent 自身能力的事**（给自己写一个新工具、招募新团队成员、连接外部服务）：永远得到最彻底的审查。对于自己写的工具，在它被允许运行之前，你看到的是**完整的源代码**，不是一段摘要；对于一个新的外部连接，你看到的是它想运行的确切命令，由你决定信不信；任何密码或 API Key 都由**你自己**直接输入，绝不经过 AI，也绝不会被它记住或写进日志。

拒绝永远是一个完全正常的结果，不是一个错误。如果你说不，AuraAgent 就会说"好的"然后转向别的办法或就此打住——它不会卡住，也不会悄悄换一种方式再试一次。

## 第五章——快速上手

你需要装好 Python，并准备一个 Anthropic（Claude）或者 OpenAI 兼容服务（OpenAI 本身，或者 DeepSeek 这类）的 API Key。

```bash
# 1. 安装依赖（建议先建一个虚拟环境）
python -m venv .venv
.venv\Scripts\activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. 配置你的 API Key
copy .env.example .env
# 用文本编辑器打开 .env，填写：
#   使用 Anthropic：AURA_LLM_PROVIDER=anthropic，然后 ANTHROPIC_API_KEY=<你的key>
#   使用 DeepSeek（或其他 OpenAI 兼容服务）：
#     AURA_LLM_PROVIDER=openai
#     OPENAI_API_KEY=<你的key>
#     OPENAI_BASE_URL=https://api.deepseek.com
#     AURA_MODEL_ID=deepseek-chat

# 3. 运行
python main.py
```

启动后会进入一个简单的输入提示，直接用大白话打字就行——"帮我创建一篇笔记记录今天的会议要点""查一下电动车最近的新闻""这周我的日历上有什么安排"。想结束就输入 `exit`。它工作的时候，你会实时看到它的思考过程、调用了什么工具、拿到了什么结果。

如果不想用命令行，也有图形化的桌面版本（见技术文档里的[运行 GUI](docs/ARCHITECTURE-cn.md#运行-guim1-m4后端前端面板桌面应用)部分）。

**想接入真实的 Google 日历，而不是内置的本地日历？** 启动 AuraAgent 后输入 `/calendar connect`，它会带你走一遍一次性的浏览器登录流程。需要提前在 Google Cloud Console 做的简单设置，见[技术文档](docs/ARCHITECTURE-cn.md)。

## 第六章——几个真实的使用场景

几句你可能真的会对它说的话：

> "查一下最近 AI 芯片的新闻，总结一下最重要的进展。"
> AuraAgent 会把这个交给调研员，它拉取近期真实的新闻标题，帮你写一份综合总结——不是简单甩给你一堆链接。

> "帮我在日历上加一条周四下午两点跟设计团队的会议，标记为重要。"
> 由日程管理员处理。因为你标了"重要"，以后任何对这条日程的改动都会先停下来问你确认。

> "把这个文件夹里的 PDF 总结成一份幻灯片。"
> 它能读你指定文件夹里的内容，真的生成一份 PowerPoint 文件——是一份实实在在的成果，不只是描述一下该怎么做。

> "我没有查汇率的工具，能帮我搞一个吗？"
> AuraAgent 会去找现成的、已经能做这件事的工具，把找到的东西和打算怎么连接完整摆给你看，你同意了才会动手。

## 第七章——做长期的 Project

有些事不是一次对话能聊完的——是持续性的。一个你会反复回来研究的课题，一项长期的个人项目，任何你希望 AuraAgent 能在几周甚至几个月里持续积累背景、而不用你每次都重新交代来龙去脉的事情。

这就是 **Project** 的用处。给它起个名字，之后：

```
/project create ai_governance                       # 为它新建一个项目文件夹
/project use ai_governance                           # 进入它——之后的文件、调研成果都落在这里
/project                                              # 查看当前激活的项目，以及列出所有项目
/project none                                         # 退出，回到你平时的工作目录
```

一旦进入某个 Project，AuraAgent 保存的任何东西——文档、笔记、调研成果——都会落进这个 Project 自己的文件夹，跟其他内容分开存放。它还会时不时记下一份简短、最新的"目前进展如何"摘要，这样下次你再输入 `/project use ai_governance`，它已经记得之前的状态了——不需要你重新介绍背景。

进入一个 Project 只对当次会话有效；每次启动 AuraAgent 默认不会自动进入任何 Project，你也可以随时在不同 Project 之间切换，或者完全退出。

在图形界面里，这个思路也延伸到了单个 Chat 上：任何不属于 Project 的 Chat，都可以单独给它指定一个工作目录（该 Chat 的 ⋯ 菜单里的"设置工作目录"），可以指向你电脑上任意一个真实文件夹——不局限于 Project 里的 Chat 才能用。如果一个 Chat 同时有 Project 和自己的目录设置，Project 的目录永远优先；把它从 Project 里移出来以后，之前设置的目录会自动重新生效，不会因为进出 Project 而丢失。

现在 Project 不只是一个文件夹加一份摘要了。它可以有自己的 **Role**——一段描述 AuraAgent 在这个 Project 里应该怎么做事的简短说明，由 AI 起草，但随时可以由你改写；也可以有自己的 **Memory**——一批只属于这个 Project 的持久事实，跟 AuraAgent 对你个人的记忆是分开的。你还可以让某个 Project 额外加载一些平时不会用到的工具——某个特定的 MCP 服务器或 Skill——这样它们只在这个 Project 激活时才会出现，不会让其他场景变得杂乱。如果你正在聊的内容其实是在同一个 Project 下的**另一个**对话里提过的，AuraAgent 也可以去那些对话里搜索，而不是把每个对话都当成从零开始。

在图形界面里，一个 Project 自己的页面把这些都拆成了独立的标签页——Role 和 Memory、已加载的工具，以及这个 Project 的文件（上传、重命名、删除、下载）——管理这些只需要点几下鼠标，不用记命令。

## 第八章——按你要求的时间点执行任务

有些事不需要你每次都开口——只需要到点自动发生：每天早上查一下什么，某个具体时间点跟进一下，每周留意一下某个话题。现在直接用自然语言跟它说就行，不管是在某个 Project 的对话里，还是完全不相关的一个新对话里，说这句话本身不需要任何命令语法：

> "每天早上9点，帮我看看 OpenAI 最近有什么新动态，写一份简短的总结。"
> "10月5日下午3点提醒我处理合同续签的事。"

它会先跟你确认细节再真正设置——这是一个会长期存在、无人值守就会执行的承诺，不是一次性动作，所以永远先问。一旦你确认，它就会在你说的时间点自己执行——可以只执行一次，也可以按你描述的周期反复执行（每小时/每天/每周指定几天/每月/每年）。如果是在某个 Project 的对话里设置的，执行时会自动带上那个 Project 的背景（目录、Role、Memory），跟你亲自打字发起是一样的效果。

有两点关于它怎么运作值得了解：因为执行过程中没有人在场回应，任何原本需要你确认的步骤都会被自动跳过，而不是干等着；另外，这个机制只在 AuraAgent 本身（终端或图形界面）处于运行状态时才会真正触发——如果到点时它没开着，下次你启动它会补跑一次，而不是悄悄错过。

你所有的定时任务——不管属于哪个 Project，还是完全不关联——都集中在一个地方管理：图形界面里的 **Schedules** 面板（终端里是 `/schedule`），在那里能看到接下来会执行什么、之前执行得怎么样，也能暂停、编辑或删除任何一条。

## 第九章——现在做到了什么，接下来会做什么

AuraAgent 是一步步搭建起来的——每一部分都先完整可用、经过测试，才会开始下一部分。到目前为止，它已经能做到：

- 进行真实的对话，在一次会话内记得上下文
- 上网调研，针对给定话题做市场/行业研究
- 管理笔记、日历（本地或真实 Google 日历）、待办事项
- 管理你电脑上的文件，包括更高级的编辑工具
- 读取、生成、编辑 Word/PowerPoint/Excel 文档，读取文字版 PDF
- 操作基本的桌面功能（剪贴板、截图、查看/关闭运行中的程序、发通知）
- 跨会话记住关于你的持久事实和一份结构化档案
- 在具名的 Project 里持续积累长期背景
- 按你要求的时间点自己执行任务，一次性或周期性，不需要人在场
- 在你批准的前提下，给自己写新工具、招募新团队成员、连接外部服务
- 既能在终端里运行，也能在图形化的桌面窗口里运行

后端现在也能被多台设备同时安全接入了，每台设备有自己独立的访问令牌（默认关闭——纯本地使用完全不受影响）——这是为将来一个配套手机 App 连接到你电脑上这同一个 AuraAgent 打的地基，不是一个今天就能单独用起来的功能，因为目前还没有任何配套 App。

往后看，眼下最优先的是**更从容地处理特别长、特别深入的调研任务**——能接着之前的进度继续，而不是做到一半就失败。定时任务（第八章）已经覆盖了"主动开口"里最具体的一种形态——一个你提前设定好的、按时间触发的承诺——但 AuraAgent 还做不到完全凭自己的判断、在没有提前设定任何时间点的情况下，主动觉得"有件新事值得跟你说一声"；这种更开放式的主动性是个更远期的目标，还没排上日程。再往后、还在观察但没排期的：真正"看懂"一张截图或一份文档图片（而不只是读出其中嵌入的文字），以及编辑 PDF 的排版，而不只是读取它。
